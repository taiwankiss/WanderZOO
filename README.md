# 動物園 3D 導覽（試做版）

用 Three.js 做的動物園 3D 導覽。目前做了臺北市立動物園的「臺灣動物區」（9 種）和「兒童動物區」（5 種）。非官方作品。

## 本機執行

ES module 不能直接用 `file://` 打開，要開一個靜態伺服器：

```bash
python3 -m http.server 8173
```

然後打開 http://localhost:8173 。網址加 `#bear` 這類動物 id 可以直接打開那隻動物；加 `?debug` 會把鏡頭和場景掛到 `window.__zoo`。

## 結構

| 檔案 | 內容 |
|---|---|
| `data/zoo.json` | 唯一的資料來源：園區、動物、展場位置與造景、步道、設施、推薦路線、時段 |
| `js/world.js` | 地形、步道、展場（不規則地面、植物邊界、柵欄或石牆、造景）、樹、設施、園區與展場名牌、路線虛線 |
| `js/animals.js` | 參數化四足動物產生器＋每隻動物的行為（閒晃、吃草、回窩休息） |
| `js/people.js` | 沿步道散步的遊客 |
| `js/ui.js` | 右側清單、推薦路線、動物卡、時段與圖層按鈕 |
| `js/main.js` | 場景、燈光（依時段變化）、鏡頭飛行、點選、導覽 |

所有模型都是程式即時生成，沒有外部 3D 檔。新增動物只要在 `zoo.json` 加一筆資料（`zone` 指定園區，`color` 用該園區的色系），再到 `animals.js` 的 `SPECIES` 補一組比例和顏色。大型展場可以在 `enclosure.barrier` 設 `fence` 或 `wall`。
